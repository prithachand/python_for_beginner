# Python String Methods for Beginners

## 1. Create / Convert Strings

-   `str()` -- Convert any object to a string.
-   `repr()` -- Official string representation.
-   `format()` -- Insert values into a string.
-   `format_map()` -- Format using a dictionary.

## 2. Search / Find

-   `find()`
-   `rfind()`
-   `index()`
-   `rindex()`
-   `count()`
-   `startswith()`
-   `endswith()`

## 3. Check / Validate

-   `isalnum()`
-   `isalpha()`
-   `isascii()`
-   `isdecimal()`
-   `isdigit()`
-   `isnumeric()`
-   `islower()`
-   `isupper()`
-   `istitle()`
-   `isspace()`
-   `isidentifier()`
-   `isprintable()`

## 4. Update / Modify

-   `replace()`
-   `lower()`
-   `upper()`
-   `capitalize()`
-   `title()`
-   `swapcase()`
-   `casefold()`
-   `strip()`
-   `lstrip()`
-   `rstrip()`
-   `center()`
-   `ljust()`
-   `rjust()`
-   `zfill()`
-   `expandtabs()`
-   `translate()`
-   `removeprefix()`
-   `removesuffix()`

## 5. Split / Break Apart

-   `split()`
-   `rsplit()`
-   `splitlines()`
-   `partition()`
-   `rpartition()`

## 6. Join / Combine

-   `join()`

## 7. Encode / Decode

-   `encode()`
-   `bytes.decode()`

## 8. Delete (Indirect)

Strings are immutable. Use: - `replace()` - `strip()` -
`removeprefix()` - `removesuffix()`
