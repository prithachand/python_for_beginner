# String Manipulations — Flash Cards

| # | Name | Snippet |
|---|---|---|
| 1 | Create a string | `text = "Hello"` |
| 2 | Concatenate | `"Hello" + " World"` |
| 3 | Repeat | `"Hi " * 3` |
| 4 | Length | `len(text)` |
| 5 | Index | `text[0]` / `text[-1]` |
| 6 | Slice | `text[0:4]` |
| 7 | Change case | `text.upper()` / `text.lower()` |
| 8 | Remove spaces | `text.strip()` |
| 9 | Replace words | `text.replace("Java", "Python")` |
| 10 | Find text | `text.find("Python")` |
| 11 | Check text | `"Python" in text` |
| 12 | Split | `text.split(",")` |
| 13 | Join | `" ".join(words)` |
| 14 | Escape characters | `"Hello\\nWorld"` |
| 15 | Format (f-string) | `f"My name is {name}"` |
